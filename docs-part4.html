5.3 Data File Outputs

XML files at backend/data/xml/ store payments, messages, logs, and reservations. JSON files at backend/data/json/ store users, rooms, and groups.

users.json — Tenant record (JSON)

{ "id": "u002", "username": "michael", "role": "tenant", "fullName": "Michael Angelo Jabagat", "roomNumber": "101", "monthlyRent": "1200", "dueDate": "6", "moveInDate": "2026-01-06" }

payments.xml — Payment record (XML)

<payment> <id>p001</id> <tenantName>Daniela</tenantName> <roomNumber>101</roomNumber> <amount>1200</amount> <method>GCash</method> <status>approved</status> <date>2026-05-05</date> </payment>

logs.xml — Activity entry (XML)

<log> <timestamp>2026-05-05T08:00:00.000Z</timestamp> <type>payment</type> <detail>Payment approved for Daniela</detail> <ref>p001</ref> </log>

5.5 How to Run the System

📋 Requirement: Docker Desktop must be installed and running. Docker only runs the infrastructure (Kafka, RabbitMQ, Redis). Frontend and backend run in your terminal.

StepCommand / Action
1. Install dependencies (first time)Double-click install.bat
2. Start infrastructureDouble-click start.bat OR run docker compose up -d
3. Run backendcd backend && npm run dev
4. Run frontendcd frontend && npm run dev
5. Open the appVisit http://localhost:3000 in any browser
6. Login as adminUsername: admin / Password: admin123
7. View logsdocker compose logs -f
8. Stop infrastructuredocker compose down
